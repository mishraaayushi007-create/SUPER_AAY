# SUPER_AAY — The Superconductor Compendium

**SUPER_AAY** is a mobile-first, 100% offline Progressive Web App (PWA) designed as an interactive learning tool for exploring superconducting materials and physics. Built with a zero-dependency frontend and an espresso-brown & pinkish-beige editorial aesthetic, it installs directly onto desktop and mobile devices for seamless offline study.

## Key Features
* **100% Offline-First PWA:** Powered by a custom Service Worker (`sw.js`) and Web App Manifest for full offline caching and native-like home screen installation.
* **Interactive Cryo-Slider Simulator:** Explore temperature-dependent superconducting transitions and critical temperature ($T_c$) behavior dynamically.
* **Material Compare Mode:** Side-by-side comparison of different superconducting materials and their physical properties.
* **Flashcard Flip Deck:** Quick-revision interactive cards covering core superconductor concepts.
* **5-Question Quiz Engine:** Built-in self-assessment tool to test comprehension offline.

## Tech Stack
* **Frontend:** Semantic HTML5, Editorial CSS3 (`style.css`), Vanilla JavaScript (`app.js`, `data.js`)
* **PWA & Offline Storage:** Service Worker API (`sw.js`), Web App Manifest (`manifest.json`), Custom Vector Icon (`icon.svg`)
